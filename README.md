I'm an electrical engineering student at NSUT Delhi. I work on how code gets compiled for GPUs, and on machine
learning systems. Recently I've been building tools that test NVIDIA's GPU toolchain and LLVM's PTX backend:
an interpreter, fuzzers, and a little formal verification.

### Selected work

<table>
<tr>
<td width="50%" valign="top">

**GPU & compilers**

- [**ptxsim**](https://github.com/Divabhattacharya/ptxsim): a PTX interpreter in C++, used for differential fuzzing and SMT-based translation validation of LLVM's NVPTX backend
- [**cuda-compiler-verify**](https://github.com/Divabhattacharya/cuda-compiler-verify): a CUDA test suite that checks results across `nvcc` and `ptxas` configurations
- [**cudasmith**](https://github.com/Divabhattacharya/cudasmith): a random CUDA program generator for compiler testing *(in progress)*
